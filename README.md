# Lake Zone Chemicals Limited CMS Website

Elegant static website and browser CMS for **LAKE ZONE CHEMICALS LIMITED**, a chemical supplier company in Tanzania.

## What is included

- Public company website: `index.html`
- CMS admin panel: `admin.html`
- Editable company profile, products, industries, and insights
- Quote request form that opens the visitor's email app
- Export/import JSON content workflow
- Responsive design for phone, tablet, and desktop screens

## How to open it

Open `index.html` in a browser to view the website.

Open `admin.html` to edit content. Click **Save Changes** after editing. Content is saved in that browser. Use **Export JSON** and **Import JSON** to move CMS content between computers.

## GitHub usage

Clone or download this repository on another PC, then open `index.html`.

For public hosting, enable GitHub Pages for the repository branch and folder that contains these files.
